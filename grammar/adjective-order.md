# Adjective order

**Rule:** Opinion → Size → Physical quality → Shape → Age → Color → Origin → Material
**Common mistake:** Using more than 3 adjectives at once — keep it natural!
**Example correct:** ✓ _a beautiful small Australian wool blanket_
**Example wrong:** ✗ _a wool Australian small beautiful blanket_
