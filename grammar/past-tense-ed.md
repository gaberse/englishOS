# past tense with -ed

**Rule:** add -ed to regular verbs for past actions. Use with: yesterday, last year, in [year], ago.
**Common mistake:** using present continuous (-ing) for past events
**Example correct:** ✓ _Yesterday I talked with my girlfriend._
**Example wrong:** ✗ _Yesterday I was talking with she._
