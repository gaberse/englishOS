# subject vs object pronouns

**Rule:** use subject pronouns (she, he, they) as the doer. Use object pronouns (her, him, them) after verbs and prepositions.
**Common mistake:** using subject pronouns after prepositions
**Example correct:** ✓ _I talk with her every day._
**Example wrong:** ✗ _I talk with she every day._
